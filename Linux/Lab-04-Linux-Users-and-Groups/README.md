# Lab 04 – Linux Users and Groups

## Objective

Learn how Linux manages users, groups, file ownership, and administrative privileges.

## Commands Practiced

- whoami
- id
- groups
- sudo
- chown
- chgrp
- ls -l
- man chown

## What I Learned

- How to identify the current user.
- How Linux uses User IDs (UID) and Group IDs (GID).
- The purpose of Linux groups.
- How file ownership works.
- How to change file ownership using `chown`.
- How to change group ownership using `chgrp`.
- Why ownership and group permissions are important in cybersecurity.

## Skills Gained

- Linux User Management
- Group Management
- File Ownership
- Administrative Privileges
- Linux Security Fundamentals
- SOC Investigation Basics
