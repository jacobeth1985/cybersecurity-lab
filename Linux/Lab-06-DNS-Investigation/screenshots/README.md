# Screenshot Guidance

No live endpoint screenshots are included in this repository. Original command output can expose usernames, computer names, internal IP addresses, remote addresses, local ports, process IDs, certificate details, or installed-software versions.

If screenshots are added later:

1. Redact or crop personal and environment-specific values before committing.
2. Keep only the evidence needed to support the learning outcome, such as an anonymized process name, service display name, path category, or `Status : Valid` signature result.
3. Use descriptive filenames, for example `01-dns-lookup-sanitized.png` or `05-authenticode-valid-sanitized.png`.
4. Do not publish screenshots containing credentials, access tokens, private URLs, full IP addresses, hostnames, or unredacted user-profile paths.

The written case study is the primary portfolio evidence because it preserves the methodology without disclosing live endpoint details.
