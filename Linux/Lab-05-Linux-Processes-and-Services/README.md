# Lab 05 – Linux Processes and Services

## Objective

Learn how to investigate Linux processes, monitor system resources, identify running services, and review system logs.

## Commands Practiced

- ps
- ps -ef
- ps aux
- top
- grep
- kill
- uptime
- systemctl
- journalctl
- journalctl -n 10

## What I Learned

In this lab, I learned how Linux manages running processes and background services.

I practiced identifying processes using `ps` and monitoring system performance with `top`. I also learned how to terminate processes using the `kill` command and verify that they had stopped.

I explored Linux services using `systemctl`, checked system uptime using `uptime`, and reviewed system logs with `journalctl`.

## Cybersecurity Perspective

These commands are valuable for SOC Analysts because they help investigate:

- High CPU usage
- Suspicious processes
- Failed services
- System events
- Security logs
- Incident timelines
