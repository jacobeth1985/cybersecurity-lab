# Week 1 – Day 3

## Topic

Linux Users and Groups

## Commands Practiced

- whoami
- id
- groups
- sudo
- chown
- chgrp

## What I Learned

Today I learned how Linux manages users and groups.

I practiced identifying my current user with `whoami`, checking my User ID and Group ID using `id`, and viewing my groups using `groups`.

I also learned how to change file ownership using `chown` and change the group owner using `chgrp`.

From a cybersecurity perspective, I learned why SOC Analysts investigate ownership changes and why privileged accounts such as members of the `sudo` group require special attention during security investigations.

## Reflection

Changing file ownership helped me understand how Linux protects important files and why attackers often target privileged accounts. This lab improved my understanding of Linux security and access control.
